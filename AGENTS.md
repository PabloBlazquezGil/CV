# Web CV (Astro)

Web estática hecha con Astro 7 + Tailwind 4. Antes de cambiar cosas de Astro, consulta su documentación actual (https://docs.astro.build); la versión puede traer cambios respecto a lo que recuerdes.

- `npm run build` genera la web en `dist/` (salida estática). Node 24 (`.nvmrc`).
- Contenido: `src/data/` (`cv_es.json`, `cv_gl.json`, `web.ts`). Páginas y componentes: `src/pages`, `src/components`. JavaScript del navegador: `src/scripts/main.ts`.
- Los comentarios del código se escriben en castellano, con tono didáctico.
